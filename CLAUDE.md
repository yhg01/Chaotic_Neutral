## Where to run

Contributors run this repository on their own machine, or on a service that they operate.
In the repository owner's sessions (`git config user.name` gives `yhg01`), all runs happen
on the owner's Mac mini, through the SSH profile `mini`, and never on the owner's laptop.
If `mini` is not reachable there, stop and tell the user. `AGENTS.md` has the full rule.
